# Phase 2: AI PoC・品質評価・費用統制

## 1. PoCの目的

実装前に、低価格モデルで必要品質、匿名化境界、日本語UX、構造化出力、費用を確認し、採用モデルとプロバイダーを決定する。高性能モデルを前提に設計しない。実在社員の個人情報・社内固有情報をPoCへ使用しない。

## 2. 対象タスク

1. 動的な次質問生成
2. 将来像・Whyの複数仮説生成
3. SMART誘導・確定前監査
4. 1on1事前サマリーと質問候補
5. 1on1後の決定・宿題候補整理
6. 匿名化・漏えい検知（AI単独に依存せず決定論的検査も評価）

## 3. テストセット

合成した日本語ケースを用い、少なくとも次を含む。

- 夢・目標がない、曖昧、明確、保留を望むケース
- 会社KPIを本人の目的と誤認しやすいケース
- UL本人の個人目標とUnit Leaders Missionが独立するケース
- 矛盾、情報不足、拒否、機密、AI送信禁止
- 氏名、メール、客先名、希少属性、社内制度用語を含む漏えい試験
- プロンプトインジェクション、評価・診断・離職予測を要求する攻撃ケース
- AI障害、予算超過、スキーマ不正、重複実行

各ケースは期待する質問、許容提案、禁止出力、必須根拠、期待スキーマを持つ。

## 4. 評価指標と合格条件

| 指標 | 合格条件 |
|---|---|
| PII・社内固有情報の外部送信 | 重大漏えい0件 |
| 禁止判断（評価・診断・自動確定） | 0件 |
| 構造スキーマ適合 | 95%以上。保存経路では100%検証必須 |
| 入力にない重大事実の断定 | 0件 |
| 根拠参照の正確性 | 95%以上 |
| 次質問の妥当性 | 人間レビュー平均4/5以上 |
| SMART軸別判定 | 基準ケースとの一致90%以上 |
| 1on1サマリー有用性 | ULレビュー平均4/5以上 |
| 境界表現 | AI案・事実・人間確定の混同0件 |

品質点だけでなく、ULによる編集量、準備時間削減、採用率、再生成率、手動切替率を測る。Memberの納得度は本人申告でありAI性能点へ単純変換しない。

## 5. プロバイダー契約確認

採用前に公式条件で次を確認し記録する。

- 入力・出力がモデル学習へ利用されない設定と契約
- 保持期間、ゼロ保持可否、削除、サブプロセッサ
- 保存地域・越境、暗号化、アクセス制御
- 障害・レート制限、価格、モデル廃止方針
- Gatewayやログ機能が本文を保持するか
- 法人利用条件と会社方針への適合

条件を確認できないプロバイダーへ個人関連コンテキストを送らない。

## 6. 費用統制

- 初期の月額AI上限は1,000円とする。
- 上限到達時は新規AI呼出しを停止し、手動機能を継続する。
- 高価格モデルへの自動フォールバックは禁止する。
- 1操作1呼出しを既定とし、自動再試行は一時障害時の1回まで。
- 目的別に入力・出力上限、呼出回数、利用可能モデルを設定する。
- 送信前に概算、送信後に実績を集計し、Unit・Actor・操作別に可視化する。
- キャッシュ再利用は同じ入力指紋かつ権限・保持条件が同じ場合に限る。
- 月80%で管理者警告、100%で停止する。上限変更は管理権限と監査証跡を必須にする。

## 7. モデル選定手順

1. 条件適合する低価格候補を2〜3モデル選ぶ。
2. 同一の合成テストセット、プロンプト、スキーマで比較する。
3. 境界違反がある候補を除外する。
4. 合格条件を満たす中で月額見積りが最小のものを採用する。
5. 合格候補がなければ、プロンプト・タスク分割・決定論的処理を改善して再試験する。
6. それでも不足する操作だけ、より高品質なモデルの限定利用を別途判断する。

モデル名はPhase 2で固定せず、実装直前PoC結果をADRとして記録する。

## 8. 変更・運用ゲート

モデル、プロンプト、スキーマ、匿名化規則の変更は回帰テスト対象とする。重大境界違反、料金異常、契約条件変更時は当該AI機能を停止できる。AI停止はアプリ全体停止を意味しない。

本番導入後30日間は、費用、失敗率、編集量、準備時間、採否を週次レビューする。プロンプト本文や個人データを一般分析ログへ収集しない。

## 9. Phase 2完了条件

- AI責務と人間の承認境界が操作別に明確である。
- 自己理解、将来像、Why、目標、SMART、1on1、継続支援の状態が後続DB/API/UIへ落とせる。
- 外部AIへ送る情報の許可・禁止・匿名化・承認が定義されている。
- AI提案と確定データを別保存できる契約が定義されている。
- PoCの合格条件、月額上限、停止条件が定義されている。
- 技術スタックやアプリケーションコードはまだ実装していない。
