# Phase 2: AIによる継続的キャリア・目標支援ロジック

## 1. 共通原則

- AIは候補、質問、整理、分析補助、品質確認を行う。
- 本人が述べた事実、本人の自己認識、UL所見、制度、システム計算、AI推測を分離する。
- AI提案は生成、確認待ち、採用、修正採用、却下、保留、失効の状態を持つ。
- AI提案には根拠、参照情報、不確実性、確認事項、有効期限を付ける。
- 人間が確認する前に正式業務データへ反映しない。

## 3. 自己分析エンジン

### 対象領域

過去経験、成功、失敗、達成感、不満、楽しかった・苦痛だった仕事、得意・苦手、興味、価値観、譲れない条件、他者評価、現在・将来skill、現場・自社課題、理想の働き方・役割・人物像。

### 動的質問選択

回答ごとに具体性、感情、意味、根拠、再現性、矛盾、心理負荷、目標関連性を評価し、次の主質問を1件選ぶ。質問typeは事実、行動、結果、感情、意味、比較、反証、他者視点、将来接続、制約確認。

### 終了条件

- 本人が終了・保留を選ぶ。
- 目的テーマが整理された。
- 新規情報が少ない。
- 心理負荷が高い。
- ULや専門窓口との対話が適切。

### 出力

経験、強み候補、価値観候補、興味、苦手、環境条件、skill、課題、探索中の問い。候補は根拠と反証を持ち、本人が採用・修正・却下・保留する。

## 4. 夢探索エンジン

夢の状態は未探索、探索中、候補あり、仮説、試行中、暫定選択、確定、再検討、保留、撤回。

AIは経験、感情、価値観、強み、興味、理想状態、制約から2〜4個の異なる方向候補を提示する。候補には根拠、必要能力、利点、負担、未確認事項、小さく試す方法を含める。本人は興味、一部一致、違う、比較、未確定を選ぶ。

「夢はありますか」で終了せず、増やしたい経験、減らしたい状態、理想の働き方、守りたい条件から探索できる。

## 5. Why探索エンジン

夢、キャリア方向、中長期目標、通過点、KPI、Mission、重要行動、目標変更へ適用する。

探索順は、達成したい理由、重要性、達成後の変化、価値提供、関連経験、価値観、将来像、本人由来性。機械的に「なぜ」を繰り返さない。

保持項目は本人原文、整理Why、根拠、経験、価値観、夢、外部要求、AI推測、本人承認、納得度、確信度、未確認事項、履歴、再確認日。

## 6. 目標形成

夢・将来像→Why→キャリア方向→中長期目標→通過点→任意のKPI/Mission→行動→成果・証拠→振り返り。

AIは複数候補を出し、本人の原文を無断置換しない。会社制度との接続なし、競合、不明、要相談を正式な状態として許容する。

## 7. SMART誘導と監査

対話中にSpecific、Measurable、Achievable、Relevant、Time-boundを引き出す。監査は各dimensionを`OK`、`IMPROVE`、`MISSING`で判定し、理由、根拠、必要情報、改善質問を返す。

正式確定は原則`MISSING`が0の場合。合理的理由があれば、対象dimension、理由、代替確認条件、再評価日、本人確認、必要時UL確認を記録して例外確定できる。

本人受入では、自分が望む、Whyを説明できる、将来像・課題と接続、会社要求なら本人の成長との関係を理解、達成基準、期限、次行動を確認する。

## 8. 継続支援

進捗は単一percentageに限定せず、状態、行動、証拠、自己評価、障害、前提変化、納得度、期限、支援、次回確認を扱う。

AIは期限接近、同じ障害、外部依存、次行動未定、達成基準との不一致、納得度低下、前提変化、支援希望を停滞候補として提示する。入力がないだけで停滞と断定しない。

## 9. Reminder

行動、途中確認、振り返り、1on1、SMART再確認、目標期限、目標更新、本人確認待ちを対象にする。目標別周期、quiet hours、snooze、digest、重複抑制を持つ。AIは通知候補を作るが外部送信を無断実行しない。

## 10. 1on1支援

共有許可された前回合意、進捗、行動、障害、自己評価、経験、成果、目標変更候補から準備sheetを作る。Memberが話したい事項を最優先する。

質問提案は質問、目的、根拠、優先度、sensitive度を持ち、ULが採用・編集・却下する。1on1後summaryはdraftで、UL確認後Memberへ共有し、Memberが訂正できる。

## 11. AI module

| module | 責務 | 禁止 |
|---|---|---|
| Conversation Orchestrator | 対話状態と次module選択 | 目標確定 |
| Self Analysis | 自己理解候補 | 性格・適職断定 |
| Experience Structuring | 状況・行動・結果・学び | 事実創作 |
| Dream Discovery | 将来像候補 | 単一路線強制 |
| Why Exploration | 理由と根拠 | 本心断定 |
| Goal Architect | 階層と候補 | 本人に代わる決定 |
| SMART Guidance/Audit | 誘導と品質確認 | 例外自動承認 |
| Evaluation Mapping | KPI・Mission接続候補 | 評価確定 |
| Progress/Reflection | 差分・学び候補 | 意欲断定 |
| Next Action | 行動候補 | task自動確定 |
| Reminder Planner | 通知計画候補 | 無断送信 |
| One-on-One | 準備・summary draft | 正式記録確定 |
| Safety/Privacy Guard | 禁止情報、scope、redaction | 組織判断 |
| Provenance Manager | 出所・根拠 | 出所改変 |
| Policy Guard | 権限・purpose | 権限外処理 |

## 12. AIが判断してはいけないこと

人事評価、昇降格、給与、配属、採用・解雇、懲戒、適職、性格、心理状態、離職、ハラスメント、夢・Why・目標、KPI正式解釈、共有、Member ranking。
