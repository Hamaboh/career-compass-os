# Phase 0: 用語集

## 1. 人・組織

| 用語 | 定義 |
|---|---|
| Member / メンバー | ULがキャリア・目標・1on1を支援する社員。MVPではアプリへログインしない |
| Unit | メンバーが所属する社内組織単位 |
| 主所属Unit | 人数・退職率・アクセス制御の基準となる正式所属Unit |
| 兼務Unit | 主所属とは別に活動するUnit。人数・退職率の分母には重複計上しない |
| Unit Leader / UL | 自Unitメンバーのキャリア・目標・1on1を支援し、データを入力・管理する利用者 |
| 上位役職者 | 全Unitを読み取り、レビューできるが、元データは原則編集しない利用者 |
| システム管理者 | 利用者、権限、制度版、AI設定、監査・運用設定を管理する技術的ロール |
| Management | Unit Leaders Mission内の役職・Gradeカテゴリー。システム管理者とは無関係で、現状KPIはdraft |

## 2. 本人中心の目標形成

| 用語 | 定義 |
|---|---|
| 幸福 | 本人が望む生活・仕事・人間関係・安心・成長等を本人の言葉で表した状態。AIが定義しない |
| ライフプラン | 仕事だけに限定しない、本人が望む中長期の生活設計 |
| キャリアプラン | 本人が望む役割、働き方、経験、スキル、選択肢の中長期計画 |
| 将来像 | 現時点の本人が望む未来の状態。仮説として作成・更新できる |
| Why | 夢・将来像・目標を本人が重要だと考える理由 |
| 目標 | 将来像への通過点として、本人とULが確認した達成対象 |
| 行動 | 目標達成に向けて実施する具体的な活動 |
| 成果・証拠 | 行動・成長・達成を裏付ける記録、成果物、フィードバック |
| SMART | Specific、Measurable、Achievable、Relevant、Time-boundの目標品質観点 |
| 本人確認済み | ULが本人へ提示し、確認日時・方法・回答を記録した状態。電子署名を意味しない |
| 確定データ | AI提案とは分離され、人間の確認手続きを経て業務上採用されたデータ |

## 3. 制度

| 用語 | 定義 |
|---|---|
| 個人評価 | 人事評価・給与制度に基づき、会社が社員個人に対して行う評価 |
| UL評価 | Unit Leaders Missionに基づき、会社がULのUnit運営・マネジメントに対して行う評価 |
| 参考情報 | 目標形成・1on1で参照できるが、本アプリが評価結果を確定しない制度情報 |
| Course | General course、Expert course等の会社制度上の区分 |
| Grade | 個人またはManagement制度上の段階。アプリの権限ロールとは別概念 |
| Leader KPI | 現在のUL評価で参照される正式カテゴリーのKPI |
| Management KPI | 現在はdraftであり、通常の評価・AI Contextに使用しないKPI |
| 制度バージョン | 制度資料の版、適用期間、状態、原本を固定した参照単位 |
| 1H | 半期。上期は1月1日〜6月30日、下期は7月1日〜12月31日 |

## 4. AI

| 用語 | 定義 |
|---|---|
| AI提案 | AIが生成した質問、整理、目標案、Why候補、SMART判定、要約等。確定データではない |
| AI推測 | 本人が明示していない理由・価値観・課題等をAIが推定したもの。事実として扱わない |
| AI匿名化ゲート | AI送信前に個人、会社、顧客、案件、制度固有情報を検出・置換し、UL承認を要求する境界 |
| 匿名化プレビュー | 外部AIへ送信する直前の置換済み本文をULが確認する画面・手続き |
| AI Context | 1回のAI処理に必要な最小限の情報。対象外Unitや機密・識別情報を含めない |
| Promptバージョン | AI処理の再現性・監査のために固定する指示テンプレートの版 |
| AI送信不可 | アプリ内には保存できるが、匿名化の有無にかかわらずAI Contextへ含めない機密区分 |
| PoC | 候補モデルの日本語品質、構造化出力、安全性、費用を実装前に比較する検証 |

## 5. 権限・情報分類

| 用語 | 定義 |
|---|---|
| ロール | 利用者が実行できる機能を定義する分類 |
| Unit scope | 利用者が扱えるUnit・メンバーのデータ範囲 |
| 通常1on1記録 | 権限内のUL・上位役職者が閲覧できる1on1記録 |
| 機密1on1記録 | 記録者と明示的に許可された利用者だけが閲覧できる記録 |
| 監査ログ | 誰が、いつ、どの対象へ、どの操作をしたかを示す追跡情報。本文を無制限複製しない |
| 期限付き共有 | 推測困難なトークン、有効期限、失効、監査を伴う本人向けレポート共有 |

## 6. データ保持

| 用語 | 定義 |
|---|---|
| 匿名化 | 個人との対応を復元できない形にし、統計だけを残す処理 |
| RPO | 障害時に許容するデータ損失時点。本MVPの初期目標は24時間 |
| RTO | 障害からサービス復旧までの目標。本MVPの初期目標は1営業日 |
