# Career Compass OS

SES企業で分散常駐する社員の自己理解、キャリア形成、目標設定、継続的な振り返り、1on1を支援する社内向けアプリケーションです。

本リポジトリは現在、設計凍結後・実装開始前の状態です。実装コードはまだありません。実装者は最初に [`docs/00-design-freeze.md`](docs/00-design-freeze.md) と [`docs/README.md`](docs/README.md) を読み、Phase 1〜4および補助仕様を一次情報として扱ってください。

## 中核原則

- 最重要価値は本人の納得感である。
- AIは質問、整理、分析補助、提案、品質確認を行うが、夢・Why・目標・人事評価を確定しない。
- AIの推測、本人の発言、本人の確認、ULの所見、会社制度、システム計算を混同しない。
- 会社KPIやUnit Leaders Missionは本人の将来像への接続を探索するが、接続を強制しない。
- フロントエンドの表示制御だけに認可を依存せず、APIとDBでも強制する。
- Memberの自己分析・夢・Why等は機微情報として扱い、本人の共有範囲を尊重する。
